# lib.scad.mechint user manual

## Use the library

Consumers import the public entrypoint:

```scad
use <openscad/sliding_dovetail.scad>

joint = sliding_dovetail_create(...);
sliding_dovetail_male_build(joint, slide_len_mm = 16);
sliding_dovetail_female_cutter(joint, slide_len_mm = 16);
```

The same interface object drives mating geometry so male/female dimensions,
clearance, optional entry-slot behavior and lock configuration stay coherent.

## Dependency boundary

`lib.scad.forge` supplies generic modeling mechanics only. Mechanical-interface
fit and locking semantics remain owned by mechint.

`lib.scad.util` is used only for section-inspection views and does not define
the mechanical interface.

## Versions

Pin an explicit released mechint version. The library itself pins exact released
Forge/util/tooling dependencies through `project.yml` plus committed gitlinks.
